# استودیوی کتاب صوتی فارسی

این نسخه توسعه همان برنامه Python/Gradio اولیه است. توابع قبلی ترجمه، خواندن فایل، انتخاب صدا، سرعت، حذف اختیاری عنوان، متن قابل ویرایش و ZIP حفظ شده‌اند. `legacy_app.py` نسخه دست‌نخورده قبلی است؛ اجرای عادی با `app.py` است.

## شروع ساده ویندوز

۱. Python 3.11 یا 3.12 را از https://www.python.org/downloads/ نصب کنید؛ گزینه Add Python to PATH را بزنید.
۲. فایل ZIP برنامه را Extract کنید.
۳. روی `start_windows.bat` دوبار کلیک کنید. بار اول اینترنت برای نصب وابستگی‌ها لازم است.
۴. مرورگر باز می‌شود؛ PDF یا TXT را انتخاب کنید و «ترجمه کامل» را بزنید.
۵. ترجمه TXT و مقایسه `bilingual.html` را دانلود کنید. HTML را با مرورگر باز کنید؛ متن اصلی و ترجمه کنار هم هستند.
۶. گزارش را بررسی کنید؛ اگر بخش ترجمه‌نشده دارید دوباره همان کتاب و تنظیمات را اجرا کنید.
۷. «ساخت کتاب صوتی» را بزنید و ZIP یا MP3ها را دانلود کنید. متن فارسی قبل از صدا قابل ویرایش است؛ متن ویرایش‌شده را برای نگهداری جداگانه کپی کنید (ویرایش، پایگاه ترجمه را تغییر نمی‌دهد).

برای نصب دستی:

```bash
python -m venv .venv
# Windows:
.venv\Scripts\activate
pip install -r requirements.txt
python app.py
```

بدون کلید، GoogleTranslator و Edge TTS کار می‌کنند؛ اینترنت و دسترسی منطقه‌ای لازم است. این مسیر رسمی Google Cloud API نیست، SLA و ترجمه نامحدود ندارد و ممکن است مسدود یا محدود شود. کیفیت صدای Dilara زنانه است؛ جوان بودن یا طبیعی بودن برای هر متن تضمین نمی‌شود. Farid صدای مرد است.

## کتاب طولانی و قطع اینترنت

متن استخراج‌شده بدون حذف کاراکتر به واحدهای حداکثر ۱۸۰۰ کاراکتری تقسیم می‌شود. فاصله‌های بین پاراگراف‌ها حفظ می‌شوند. هر واحد شناسه ثابت و ترجمه مستقل دارد. SQLite بعد از هر بخش commit می‌شود. اگر برنامه یا اینترنت قطع شد همان فایل، واژه‌نامه، موتور، مدل و حالت قبلی را دوباره انتخاب و «ترجمه کامل / ادامه ترجمه» را بزنید. کلید را دوباره وارد کنید. تغییر تنظیمات یک پروژه مجزا ایجاد می‌کند.

پوشه پیشرفت در ویندوز `%USERPROFILE%\.persian-podcast-studio` است. می‌توانید پیش از اجرا متغیر `PPS_DATA_DIR` را به پوشه شخصی دیگری تنظیم کنید. برای ادامه، این پوشه باید باقی بماند. نسخه پشتیبان ZIP شامل ترجمه، گزارش و `checkpoint.sqlite` است. برای بازیابی دستی، برنامه را ببندید، پوشه پروژه با شناسه نمایش‌داده‌شده را ایجاد کنید، `checkpoint.sqlite` را با نام `progress.sqlite` در آن قرار دهید و همان فایل و تنظیمات را اجرا کنید. در بازیابی، فقط از نسخه پشتیبان خودتان استفاده کنید. فایل‌های WAL/SHM پروژه قدیمی را همراه دیتابیس جدید استفاده نکنید؛ در پوشه جدید بازیابی کنید.

فایل صوتی ساخته‌شده نیز بر اساس متن، صدا و سرعت در پوشه مجزا ذخیره می‌شود؛ تکرار درخواست از قسمت‌های موفق استفاده می‌کند. تکمیل‌شدن MP3 بر اساس غیرخالی بودن فایل کنترل می‌شود، نه تطبیق گفتار با تمام متن. هر بخش MP3 حدود ۱۸۰۰ کاراکتر است. در صورت نصب FFmpeg در PATH، هر ۲۰ بخش به یک قسمت بلندتر `section_*.mp3` تبدیل می‌شود. این قسمت‌بندی بر اساس اندازه است؛ تشخیص خودکار فصل واقعی و نگهداری صفحه‌آرایی PDF پیاده نشده است.

## کیفیت و پوشش کامل

برنامه خلاصه‌سازی نمی‌کند؛ همه متن استخراج‌شده وارد صف می‌شود. هیچ عنوانی به‌صورت پیش‌فرض حذف نمی‌شود. گزینه حذف خط اول، حذف عمدی و اختیاری است.

گزارش `quality.json` تعداد واحدها، شناسه بخش‌های ترجمه‌نشده، خروجی بسیار کوتاه، نبود خط فارسی، عددهای گمشده و اصطلاحات ناسازگار با واژه‌نامه را نشان می‌دهد. خروجی مشکوک برای بررسی نگه داشته می‌شود؛ موفقیت ساختاری به معنی تضمین کامل بودن معنایی نیست. وجود همه مثال‌ها یا صحت ترجمه علمی تنها با کنترل تعداد بخش‌ها قابل اثبات نیست. تصویر، فرمول تصویری، جدول چندستونه، نمودار و ترتیب خواندن PDF ممکن است خطا داشته باشند. PDF اصلی را با HTML مقایسه کنید. صفحات بی‌متن و صفحات دارای تصویر هشدار می‌گیرند؛ هیچ صفحه ناموفق پنهانی ترجمه‌شده اعلام نمی‌شود.

واژه‌نامه را در تنظیمات وارد کنید، مثلاً:

```json
{"machine learning":"یادگیری ماشین", "gradient":"گرادیان"}
```

مدل‌های LLM این واژه‌نامه را در دستور ترجمه و بازبینی دریافت می‌کنند؛ Google فقط از نظر رعایت آن کنترل می‌شود و معادل‌ها به اجبار در متن جایگزین نمی‌شوند. واژه‌نامه خودکار و حافظه معنایی بین فصل‌ها در این نسخه وجود ندارد.

حالت سریع یک موتور دارد. حالت دقیق به موتور/مدل متفاوت برای بررسی مستقل و اصلاح همان متن نیاز دارد. اگر بازبین قطع شود بخش جاری کامل علامت نمی‌خورد؛ ممکن است فقط همان بخش دوباره ترجمه شود. حالت دقیق خودکار کیفیت مطلوب همه کتاب‌ها را تضمین نمی‌کند. انتخاب خودکار بهترین موتور از بین حساب‌های ناشناخته، یا fallback پنهان به سرویس پولی انجام نمی‌شود.

## موتورهای اختیاری و هزینه صفر

| موتور | روش استفاده | محدودیت |
|---|---|---|
| Google | پیش‌فرض، بدون کلید | سرویس غیررسمی، احتمال محدودیت و افت کیفیت |
| Ollama | نصب از https://ollama.com و اجرای `ollama pull qwen2.5:7b`؛ مدل را `qwen2.5:7b` بگذارید | ترجمه محلی بدون هزینه API، نیازمند دانلود چندگیگابایتی و RAM مناسب؛ کیفیت فارسی وابسته به مدل |
| Gemini | کلید از https://aistudio.google.com/apikey؛ نام مدل دارای Free Tier را از مستندات جاری انتخاب کنید | فقط پروژه بدون billing؛ سهمیه، کشور و دسترسی حساب متغیر است |
| Groq | کلید از https://console.groq.com/keys؛ مدل موجود در حساب رایگان را انتخاب کنید | محدودیت توکن/روز و درخواست؛ نمونه مدل را از Console همان روز بردارید |
| OpenRouter | کلید از https://openrouter.ai/keys؛ مدل `openrouter/free` یا نام ختم‌شونده به `:free` | انتخاب مدل پولی در کد مسدود است؛ سهمیه کم، دسترسی متغیر |
| Hugging Face | بررسی شد، adapter آنلاین اضافه نشده | اعتبار رایگان بسیار کوچک و برای کتاب کامل مناسب نیست؛ مدل‌های قابل دریافت را می‌توان با موتور محلی سازگار اجرا کرد |

برای Gemini و Groq برنامه نمی‌تواند رایگان بودن حساب را از خود کلید تشخیص دهد. فقط از حساب بدون صورتحساب استفاده کنید؛ تأیید تنظیمات لازم است. هیچ کارت بانکی یا پرداختی برای اجرای پایه لازم نیست. سهمیه تمام شود، کار متوقف و قابل ادامه می‌ماند؛ سرویس پولی جایگزین نمی‌شود. کلیدها در پایگاه داده، تنظیمات پروژه یا مخزن نوشته نمی‌شوند و تنها برای درخواست API در حافظه مصرف می‌شوند. کلید را در فایل عمومی نگذارید.

منابع رسمی بررسی‌شده (۲۶ اکتبر ۲۰۲۶):
- https://ai.google.dev/gemini-api/docs/pricing
- https://console.groq.com/docs/rate-limits
- https://openrouter.ai/pricing
- https://huggingface.co/docs/inference-providers/pricing

## OCR رایگان

Tesseract و داده زبان `eng` را نصب کنید؛ PyMuPDF از موتور Tesseract استفاده می‌کند. در ویندوز راهنمای https://tesseract-ocr.github.io/tessdoc/Installation.html را ببینید. در صورت لزوم `TESSDATA_PREFIX` را روی پوشه tessdata قرار دهید. سپس گزینه OCR را فعال کنید. تمام صفحات با ۲۰۰ DPI پردازش می‌شوند تا نوشته داخل تصاویرِ صفحه‌های ترکیبی هم نادیده نماند؛ کندتر است و خطای OCR امکان‌پذیر است. OCR شکست‌خورده با خطا متوقف می‌شود.

## حریم خصوصی و پاک‌سازی

اجرای پیش‌فرض فقط روی `127.0.0.1` و بدون لینک اشتراکی است. Google/Gemini/Groq/OpenRouter متن را دریافت می‌کنند؛ برای ترجمه خصوصی Ollama را استفاده کنید. Edge TTS متن فارسی را به Microsoft می‌فرستد. نسخه رایگان بعضی سرویس‌ها ممکن است از داده‌ها برای بهبود سرویس استفاده کند؛ شرایط سرویس را بررسی کنید.

متن اصلی و ترجمه برای ادامه کار فقط محلی نگهداری می‌شوند؛ پس از دانلود خروجی و بستن برنامه می‌توانید پوشه پروژه را از مسیر بالا حذف کنید. فایل‌های upload موقت Gradio هم در مسیر موقت سیستم هستند؛ آن‌ها را از تنظیمات سیستم پاک کنید. حذف خودکار پیشرفت فعال نیست تا کار چندروزه از بین نرود. این نسخه برای یک کاربر محلی است؛ بدون احراز هویت، جداسازی کاربران و سیاست نگهداری داده روی اینترنت عمومی منتشر نکنید.

## میزبانی رایگان و نسخه اجرایی

GitHub Pages نمی‌تواند Python را اجرا کند. Hugging Face Spaces با Gradio روی CPU رایگان گزینه آزمایشی است: https://huggingface.co/docs/hub/spaces-overview . خواب، restart، محدودیت CPU و فضای موقت دارد؛ برای کتاب چندروزه، اجرای محلی مطمئن‌تر است. برای Space باید launch با `server_name='0.0.0.0'`، `inbrowser=False` باشد و مسیر داده جداگانه و ورود کاربر اضافه شود. نسخه فعلی عمداً پیش‌فرض محلی دارد؛ آماده سرویس عمومی چندکاربره نیست.

فایل workflow ویندوز در `.github/workflows/windows-build.yml` با اجرای دستی GitHub Actions یک پوشه portable با PyInstaller می‌سازد. لازم نیست کاربر نهایی Python نصب کند، اما build و اجرای EXE روی ویندوز در این محیط آزمایش نشده است. FFmpeg و Tesseract داخل آن بسته‌بندی نمی‌شوند. در این تحویل EXE آزمایش‌شده ارائه نشده؛ روش bat مسیر پشتیبانی‌شده فعلی است.
